# Faculdade-fla

Projeto de interface web desenvolvido em aula na Faculdade Flamingo.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Página principal em `index.html`; estilos em `css/style.css`.

A versão deste repositório aplica Flexbox como exercício adicional ao layout da aula.

**Tecnologias:** `CSS`, `HTML`.

## Visualizar localmente

Use um servidor HTTP local para abrir `index.html`.
